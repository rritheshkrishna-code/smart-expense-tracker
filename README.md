# Smart Expense Tracker

A responsive web application for managing personal income and expenses.

## Features

- Add income and expense transactions
- Categorize transactions
- Automatically calculate total income
- Automatically calculate total expenses
- Automatically calculate remaining balance
- Delete transactions
- Store transactions using LocalStorage
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## How It Works

Users can enter a transaction description, amount, type, and category.

JavaScript processes the transaction and updates the balance, income, and expense values dynamically.

LocalStorage is used to persist transaction data even after refreshing the browser.

## Future Improvements

- Expense charts and graphs
- Monthly expense reports
- Search and filter transactions
- User authentication
- Cloud database integration
